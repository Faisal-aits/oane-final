# Client Requirements Guide for Onae

This document outlines the necessary information, credentials, and assets we need from the client (Onae) to fully configure and launch the project.

## 1. Contact Form & Email Notifications
To enable the website to send emails when someone fills out the contact form, we need a dedicated Gmail account.
* **Gmail Email Address**: The email address from which the website will send notifications (e.g., `contact@onae.com` or `onaewebsite@gmail.com`).
* **Gmail App Password**: We need an App Password generated from the Google Account to securely send emails without exposing the actual account password. 
  * *Instructions for Client:* Go to Google Account > Security > 2-Step Verification > App Passwords > Create an App Password and provide it to us.

## 2. Google Sheets Integration (Lead Storage)
To save all contact form submissions into a Google Sheet automatically, we need the following:
* **Google Sheet**: Create a new Google Sheet where you want the submissions to be stored.
* **Share Access**: The client needs to share this Google Sheet with our Google Service Account Email (we will provide this specific email address to the client to add as an "Editor").
* **Google Sheet ID**: The unique ID from the Google Sheet URL (the long string of characters between `/d/` and `/edit` in the browser link).

## 3. Hosting and Domains
* **Domain Name**: Does the client already own a domain name (e.g., `onae.com`)? If yes, we need access to the domain registrar (like GoDaddy, Namecheap, etc.) to point it to our hosting servers.
* **Hosting Preferences**: Let us know if the client has preferred hosting platforms, or if we should use our standard recommendations (e.g., Vercel for frontend, Render/Railway for backend).

## 4. Content and Branding Assets
If the website design is still missing final content, please provide:
* **High-Resolution Logos**: Primary, secondary, and favicon variations (SVG or transparent PNG preferred).
* **Brand Colors & Typography**: Official color codes (HEX) and font families.
* **Copywriting**: Final text for the landing page, About section, services, etc.
* **Images/Media**: Any specific photos, videos, or illustrations to be used on the site.

## 5. Social Media Links
* Links to the official social media profiles (Instagram, Twitter/X, LinkedIn, Facebook, etc.) to link in the footer/header.
